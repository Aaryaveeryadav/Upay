Response headers

Before this change the local server sent 2 headers and vercel.json sent none — the deployed site had no CSP and could be framed.

What the CSP had to allow

Derived from the app's real surface, not a template. Each allowance is a documented cost, not an oversight.

AllowanceCountReason
script-src 'unsafe-inline'1 inline Supabase bootstrap in index.html; a nonce means templating it per request
style-src 'unsafe-inline'261 inline style attributes in the renderer
img-src data:33 figure diagrams inlined as data URIs
connect-src2 this origin plus one Supabase project — nothing else
The distinction that matters: upgrade-insecure-requests is sent by Vercel, where everything is HTTPS, but not by the local server. On a school LAN reached over plain HTTP that directive rewrites every subresource to https and breaks the page. Sending the same CSP everywhere would have looked tidy and broken the offline use case.

Still open — and this is the important part

The site is hardened, but the site is not yet secure, and no header can make it so.
  • An exposed legacy Supabase service-role key is still live. Code changes here do not revoke it. It must be deactivated in the Supabase dashboard and its JWT signing secret rotated.
  • Old Gemini keys must be treated as compromised and revoked in Google AI Studio.
  • No durable rate limiting on paid AI. The current throttle is in-memory and does not survive a restart or span instances.
  • No UPAY_AI_ALLOWED_USERS allowlist at deployment. Any auto-confirmed sign-up can currently reach the paid provider key.

These are dashboard and policy actions, not code. They are listed as items 1–6 in SECURITY-AND-QA.md. Also note the CSP relies on 'unsafe-inline' for scripts, so it raises the cost of an injection rather than eliminating it — the real defence is that every question field passes through esc(), which the payload tests above confirm.

This is a targeted audit, not a third-party penetration test. It does not establish that the site is immune to attack; it establishes that the listed defects are fixed and the listed probes fail.
